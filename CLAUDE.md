# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием. Описание
репозитория (установка, архитектура, конфигурации) — в README, он
импортируется целиком:

@README.md

## Правила

- Комментарии в коде на английском языке.
- Язык общения задан глобально через `language` в `claude/.claude/settings.json`.
- При любых изменениях в репозитории (добавление/удаление инструментов,
  изменение структуры, новые скрипты) — обновлять `README.md`, чтобы он
  отражал актуальное состояние проекта.
